# javaScriptfundamentos03

Continuação dos estudos de JavaScript com foco em funções, métodos de array, objetos , JSON e introdução á programação Orientada a objetos.

## Objetos

Ao final deste projeto, o aluno deverá ser capaz de:

- Criar e utilizar funções;
- Trabalhar com parâmetros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Trabalhar com array de objetos;
- Entender o uso de `this`;
- Converter objetos para JSON e JSON para objetos;
- Criar classe;
- Utilizar `construtor`;
- Instanciar objetos com `new`;
- Criar atributos e métodos;
- Compeender os conceitos iniciais de encapsulamento, herança e polimorfismo;

## Como executar

Abra o terminal na pasta de projeto e execute:

bash
    node nome-do-arquivo.js
